วิเคราะห์ปัญหาและบันทึกสิ่งที่ทำแล้ว

เลือกอาการ ระบุผลแต่ละขั้น แล้วทำตามคำแนะนำจากต้นทางไปยังปลายทาง

บันทึกอัตโนมัติ

บันทึกผลการตรวจแต่ละขั้น

เรียงตามลำดับที่แนะนำ หากพบปัญหาให้แก้จุดนั้นก่อน แล้วจึงตรวจขั้นถัดไป

ทำแล้ว 0 จาก 6 ขั้น
  1. 1

    ตรวจว่ากระทบอุปกรณ์อื่นด้วยหรือไม่

    สอบถามผู้ใช้ใกล้เคียง หรือทดสอบอุปกรณ์อื่นบนเครือข่ายเดียวกัน เพื่อแยกปัญหาเครื่องเดียวกับปัญหาส่วนกลาง

  2. 2

    ตรวจสาย LAN หรือ Wi-Fi

    ดูสถานะ Wi-Fi / ไฟที่พอร์ต ตรวจสายให้แน่น หรือทดลองเชื่อมต่อเครือข่ายที่ถูกต้องก่อนใช้คำสั่ง

  3. 3

    ตรวจ IP Address และ Gateway

    เรียก ipconfig /all แล้วดูว่า IPv4, Subnet Mask และ Default Gateway มีค่าถูกต้องหรือไม่

    ipconfig /all
  4. 4

    ทดสอบการเชื่อมต่อ Gateway

    Ping ไปยัง Gateway ของเครื่อง หากยังไม่ทราบให้กรอกในส่วนข้อมูลอุปกรณ์ก่อน

    ping 192.168.1.1
  5. 5

    ทดสอบการเชื่อมต่ออินเทอร์เน็ต

    เมื่อ Gateway ตอบกลับแล้ว ให้ทดสอบ Public IP เพื่อแยกปัญหาเครือข่ายภายในกับทางออกอินเทอร์เน็ต

    ping 8.8.8.8
  6. 6

    ตรวจการทำงานของ DNS

    หาก Public IP ตอบกลับ แต่เปิดเว็บด้วยชื่อไม่ได้ ให้ตรวจการแปลงชื่อโดเมน

    nslookup google.com

Windows
IPข้อมูลเครือข่าย

ตรวจสอบข้อมูล Network Adapter

ipconfig /all

ดู IP Address, Gateway, DNS และรายละเอียดอะแดปเตอร์เครือข่ายทั้งหมด

GWทดสอบการเชื่อมต่อ

ทดสอบการเชื่อมต่อ Gateway

ping 192.168.1.1

ตรวจสอบว่าเครื่องติดต่อเราเตอร์หรือ Default Gateway ได้หรือไม่

IPทดสอบการเชื่อมต่อ

ทดสอบการเชื่อมต่อ Public IP

ping 8.8.8.8

ทดสอบการเชื่อมต่ออินเทอร์เน็ตไปยัง Public IP ของ Google

TRตรวจสอบเส้นทาง

ตรวจสอบเส้นทางเครือข่าย

tracert 8.8.8.8

แสดงเส้นทางและจุดต่าง ๆ ที่ข้อมูลเดินทางไปยังปลายทาง

DNSตรวจสอบ DNS

ตรวจสอบการแปลงชื่อโดเมน

nslookup google.com

ตรวจสอบว่า DNS แปลงชื่อโดเมนเป็น IP Address ได้หรือไม่

PCข้อมูลคอมพิวเตอร์

ตรวจสอบชื่อคอมพิวเตอร์

hostname

แสดงชื่อเครื่องคอมพิวเตอร์ที่กำลังใช้งาน

DNSแก้ไขปัญหา DNS

ล้าง DNS Cache

ipconfig /flushdns
