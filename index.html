Network Troubleshooting Toolkit

เครื่องมือช่วยตรวจสอบและแก้ไขปัญหาเครือข่าย สำหรับเจ้าหน้าที่ IT Support

เครื่องมือคำสั่ง

ศูนย์รวมคำสั่งเครือข่าย

Windows

เลือกคัดลอกคำสั่ง แล้วเปิด Command Prompt หรือ PowerShell เพื่อเรียกใช้งาน

IPข้อมูลเครือข่าย

ตรวจสอบข้อมูล Network Adapter

ipconfig /all

ดู IP Address, Gateway, DNS และรายละเอียดของอะแดปเตอร์เครือข่ายทั้งหมด

GWทดสอบการเชื่อมต่อ

ทดสอบการเชื่อมต่อ Gateway

ping 192.168.1.1

ตรวจสอบว่าเครื่องติดต่อเราเตอร์หรือ Default Gateway ได้หรือไม่

IPทดสอบการเชื่อมต่อ

ทดสอบการเชื่อมต่อ Public IP

ping 8.8.8.8

ทดสอบการเชื่อมต่ออินเทอร์เน็ตไปยัง Public IP ของ Google

TRตรวจสอบเส้นทาง

ตรวจสอบเส้นทางเครือข่าย

tracert 8.8.8.8

แสดงเส้นทางและจุดต่าง ๆ ที่ข้อมูลเดินทางไปยังปลายทาง

DNSตรวจสอบ DNS

ตรวจสอบการแปลงชื่อโดเมน

nslookup google.com

ตรวจสอบว่า DNS แปลงชื่อโดเมนเป็น IP Address ได้หรือไม่

PCข้อมูลคอมพิวเตอร์

ตรวจสอบชื่อคอมพิวเตอร์

hostname

แสดงชื่อเครื่องคอมพิวเตอร์ที่กำลังใช้งาน

DNSแก้ไขปัญหา DNS

ล้าง DNS Cache

ipconfig /flushdns

ล้างข้อมูล DNS ที่บันทึกไว้ชั่วคราว เพื่อแก้ปัญหาการค้นหาชื่อโดเมน

บันทึกข้อมูลเครื่องและคัดลอกเป็นข้อความเพื่อแนบในบันทึกการแก้ไขปัญหา
